ZAYN — حارس العوالم | المستوى الأول

محتويات الحزمة:
- حركة زين والقفز والاندفاع
- الصحة والطاقة والدرع
- الهجوم القريب والطاقة والقدرة النهائية
- أعداء ومطاردة وهجوم
- زعيم حارس الشق
- المهمة الأولى
- العملات والخبرة
- واجهة UI
- تحكم الجوال وعصا الحركة

تنظيم المشهد:
1) أنشئ Player باسم Zayn وأضف CharacterController و ZaynCompleteGame.
2) أنشئ AttackPoint و FirePoint واربطهما.
3) أنشئ Enemy Prefab وأضف ZaynEnemy.
4) أنشئ Boss Prefab وأضف ZaynBoss.
5) أنشئ Energy Prefab مع Collider Trigger وأضف ZaynProjectile.
6) أنشئ Canvas: HealthBar, EnergyBar, MissionText, CoinsText.
7) أنشئ Joystick واربط ZaynMobileJoystick.
8) أضف أزرار UI واربطها: AttackButton / EnergyButton / JumpButton / DashButton / ShieldButton / UltimateButton.

هذه حزمة منطق وبرمجة للمستوى الأول. الموديلات 3D والأنيميشن والموسيقى والخريطة والشوارع تُضاف كأصول داخل Unity.
